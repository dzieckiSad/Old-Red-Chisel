# Working rules (from the owner)

- **Everything visual is custom-made.** UI elements, graphics, icons, frames, borders, widgets, interactive and animated elements are designed and built in this repo. Do not add UI component libraries, icon packs or ready-made widgets. A ready-made piece is allowed only if it's genuinely good, and then it gets edited to match our design.
  Plain tooling (Next.js, Tailwind, Stripe, CMS) is fine; what the visitor sees is ours.
- **Questions go through a form.** Whenever input from the owner is needed, ask with the multiple-choice question form (AskUserQuestion), not in plain chat text.
- The owner writes in Polish: reply in Polish. Site content is in English.
